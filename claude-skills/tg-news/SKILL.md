# Новости из Telegram (команда «новости»)

Папка: `C:\Users\User\tg_monitor`. Python — системный `python` (C:\Python314), библиотеки requests/bs4/lxml стоят.
Панель: артефакт «Рабочая панель» https://claude.ai/artifact/9mbsDoDoHmQg5ZyXGK368R

## Правила пользователя

- Команда «новости» = весь цикл сразу, без лишних вопросов: сбор → разбор → панель → открыть.
- **Старые новости не удалять.** База `tg_monitor.db` только пополняется; панель показывает
  последние 45 дней (`WINDOW_DAYS`), минимум месяц. Пересказы в `notes.json` не стирать.
- Дата и время обновления — в шапке панели (ставится автоматически).
- Расписание/Планировщик не ставить — только по команде.
- Объяснять по-русски, просто.

## Шаги

1. `cd C:\Users\User\tg_monitor; $env:PYTHONIOENCODING='utf-8'; python news.py`
   — собирает новые посты (догоняет пропуски до 31 дня назад, листая страницы t.me/s/),
   строит `news_panel.html` и печатает «НУЖЕН РАЗБОР» — новые посты без пересказа.
   Вывод длинный: читать сохранённый файл целиком.
2. Разобрать каждый новый пост в `notes.json` (ключ `"канал/номер"`), дописывая, не перезаписывая:
   - `biz` — Shopify, дропшиппинг, маркетплейсы, тренды, реклама, платёжки, поставщики;
   - `tool` — Claude Code, агенты, модели, инструменты, которые реально пригодятся;
   - `soft` — продажа услуг/партнёрств, фон, для сведения;
   - `skip` — реклама, пустые посты, дубли (в базе остаются, на панель не идут);
   - `course` — только для slivaker_it: курс пересекается с нашими задачами → зелёная карточка
     в «Свежих курсах», в `for_us` одна фраза «зачем». Остальные курсы канала показываются сами
     (разбор «Название / Размер: / Цена:»), их помечать `skip`.
   Ленты всех постов на панели нет (пользователь убрала 22.09) — только «Главное» и курсы.
   **Установленное из новостей помечать всегда** (просьба пользователя 22.09): когда ставим скилл,
   MCP или репозиторий с GitHub из поста — в notes.json этого поста дописать
   `"tool": "короткое имя", "installed": "дата — что и куда поставили, ссылка"`; если решили не ставить —
   `"declined": "причина"`. На карточке появится зелёная «✓ Установлено» / серая «Не ставили»,
   а в шапке панели — строка «Из новостей установлено: …» (берётся из всех заметок, не только за 45 дней).
   Формат: `{"cat", "headline", "summary": [абзацы], "for_us": "что это значит для нас"}`.
   В тексте `код` в обратных кавычках станет `<code>`. Одинаковый пост в двух каналах —
   пересказ одному, второму `skip`. Громкие заявления каналов (новые модели и т.п.) подавать как
   «канал пишет», не как факт.
   Удобно: python-скрипт в scratchpad, который грузит notes.json, делает `update(new)` и
   `setdefault(key, {"cat": "skip"})` для остальных новых постов (`scraped_at >= last_collect_started`
   из `panel_state.json`).
3. `python news.py --build` — пересобрать панель с пересказами.
4. Опубликовать `news_panel.html` в Artifact с `url` панели (выше), без `icon`.
   Если Artifact отвечает 403 — открыть локально `Start-Process news_panel.html` и сказать об этом.
5. Коротко в чате: сколько новых постов, 3–5 главных новостей одной строкой каждая, ссылка.

## Файлы

| Файл | Что это |
|---|---|
| `tg_monitor.py` | старый сборщик (функции fetch/parse/save_media используются news.py) |
| `news.py` | сбор с догоном + сборка панели |
| `channels.txt` | список каналов |
| `notes.json` | пересказы и пометки skip — копятся, не удалять |
| `panel_state.json` | время последнего сбора → метка «новое» |
| `panel_extra.html` | подборка «Курсы — что купить» (статичная, правится руками); ниже неё автоматический список свежих курсов |

Вид панели (решения пользователя 22.09): «по делу» и «лично тебе» — два столбца рядом (на телефоне друг под другом), «фоново» — под ними, дальше курсы.
| `media/<канал>/` | фото и видео постов |
